# RAVENTA Control Center — consolidated module

This module preserves the useful HMS + Security control-center concept from the historical `RAVENTA` prototype.

## Scope

- HMS and security control registration
- severity and lifecycle status
- KPI overview
- filtering by domain
- lifecycle: registration → risk → action → verification → closure

The module is a portfolio/demo component. It does not claim regulatory compliance, clinical validation, production security, or suitability for operational safety decisions.

Source: historical `abla86/RAVENTA` implementation. The original repository remains historical; this module is the canonical HealthTech portfolio destination.
