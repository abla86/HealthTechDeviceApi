# SKILL.md

## Purpose
Combined healthcare-device platform demonstrating application engineering across API, domain, data, DICOM and delivery layers.

## Skills demonstrated
- C#/.NET and ASP.NET Core REST APIs
- Layered architecture, dependency injection and repository boundaries
- Validation and controlled request handling
- Synthetic DICOM generation and bounded metadata inspection
- Automated tests, Docker and GitHub Actions
- CodeQL/Dependabot-oriented DevSecOps
- Browser dashboard integration

## Evidence rule
Healthcare data is synthetic. Do not infer clinical validation from software tests.

## Maintenance
Every claimed capability must remain traceable to source code and automated or documented verification.
